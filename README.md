# JudgeCal

A calibration and reliability audit toolkit for LLM-as-judge pipelines. Measures human agreement, position/length/self-preference bias, and run-to-run consistency, and rolls them into a transparent 0-100 trust score with a usage recommendation.

Status: early skeleton (Milestone 1 in progress). See `docs/BRIEF.md` for the full project brief and `CLAUDE.md` for conventions.
